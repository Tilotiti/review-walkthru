# Security

Report a vulnerability through [a private security advisory](https://github.com/Tilotiti/review-walkthru/security/advisories/new), not a public issue. You will get an answer within a week.

Review Walkthru runs on your machine: a relay on `127.0.0.1` serves the review page behind a random token, and the Chrome extension acts only on that page. Reports about either are in scope.
