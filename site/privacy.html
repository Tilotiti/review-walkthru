Review Walkthru

Privacy

Last updated on October 31, 2026.

The Chrome extension

The extension collects no data. It sends nothing to any server, stores nothing, and contains no analytics.

It runs on pages served from http://127.0.0.1 and acts only on the review page that the plugin starts on your computer. From that page it reads one value, the address of your local app, and opens that address next to the page in a Chrome split view. When you click a link to the app, it loads the link in the app's half of the split.

The Claude Code plugin

The plugin keeps each review in ~/.claude/plugins/data/ on your computer: the scenario, your comments, and the test accounts it created. A relay on 127.0.0.1 serves the review page; nothing else can reach it.

The plugin uses your own GitHub CLI to read the pull request. It writes nothing on GitHub, and pushes fixes only after you approve them in the conversation.

The review you send goes to Claude Code, which handles it like any other prompt, under the terms you accepted for Claude Code.
